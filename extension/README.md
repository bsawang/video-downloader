# 短视频下载器 · 浏览器插件

抖音视频**无水印下载**（无后端，页面内直接下载）。MV3 浏览器扩展，全站统一"视频上叠下载按钮"交互。

## 支持平台

| 项目 | 支持情况 |
|---|---|
| **浏览器** | Google Chrome、Microsoft Edge（Chromium 内核）✅ |
| | 其他 Chromium 内核（Opera / Brave 等）✅ 理论上可用 |
| | Firefox、Safari ❌ 未适配 |
| **浏览器版本** | Chrome / Edge **111+** |
| **适用网站** | 抖音 **www.douyin.com**（精选 / 栏目 / 搜索 / 详情页） |
| **系统** | Windows / macOS / Linux（跨平台） |
| **登录要求** | 建议已登录抖音（未登录部分页面无数据） |

## 功能特性

- **全站覆盖**：首页精选、频道栏目（公开课/知识/美食…）、搜索结果（多列 + 单列大视频流）、视频详情页
- **迅雷式交互**：视频卡片 / 播放器 **hover** 出现下载按钮，平时隐藏不遮挡内容
- **清晰度选择**：点按钮弹出菜单，选 1440p / 1080p / 720p / 540p 等
- **无水印**：直链无水印下载
- **无后端**：纯浏览器扩展，数据从页面内提取，不依赖服务器

## 安装（Chrome / Edge）

**方式一：安装包（推荐，给使用者）**

从项目 [Releases](../../releases) 下载最新 `video-downloader-v*.crx`：

1. 打开 `chrome://extensions`（Edge 用 `edge://extensions`）
2. 右上角开启 **开发者模式**
3. 把 **.crx 文件拖进浏览器窗口** → 确认安装
4. 打开抖音（建议已登录）

> 也可用 `.zip`：解压 → chrome://extensions → **加载已解压的扩展程序** → 选解压目录。

**方式二：源码加载（给开发者）**

1. `chrome://extensions` → 开启开发者模式
2. **加载已解压的扩展程序** → 选择本目录 `extension/`
3. 确认版本 **0.5.2**

> **升级**：先**移除旧版**再重新安装（内容脚本有浏览器缓存，移除重装最稳妥）。

## 使用

| 操作 | 说明 |
|---|---|
| 鼠标移到视频卡片 / 播放器 | 出现 **⬇** 图标（列表卡片）或 **⬇ 下载**（播放器） |
| 点击图标 | 弹出清晰度菜单 |
| 选择清晰度 | 开始下载，文件名 `作者_标题_清晰度.mp4` |
| 页面底部 toast | 显示下载进度 / 完成 / 失败 |

覆盖场景：

- **首页 / 精选页**：每个视频卡片 hover 出图标
- **频道栏目**：公开课、知识、美食、旅行、音乐等，切换栏目后新卡片同样生效
- **搜索结果**：多列瀑布流、单列大视频流（播放中的视频）
- **视频详情页**：播放器右下角 **⬇ 下载** 大按钮

## 注意事项

- **需登录抖音**：未登录时搜索页等不渲染结果，无数据可下载
- **图文笔记无图标**：非视频内容（图文）没有下载按钮，属正常
- **hover 才显示**：按钮默认隐藏，鼠标移到视频上才出现（设计如此，不遮挡封面）
- 视频文件较大（几十~几百 MB），下载时请耐心等待

## 技术说明（开发者）

- `content/main.v05.js`（页面世界）：**通用视频提取** —— hook 所有 fetch/XHR，响应用 `text()` 逐行解析（兼容流式帧 `general/search`），递归找含 `aweme_id + video.bit_rate` 的条目，精简后转发隔离世界
- `content/isolated.v054.js`（隔离世界）：**多锚点匹配** + hover 按钮 + 清晰度 popover + 下载
  - 锚点：`[data-aweme-id]`（首页/精选）、`[id^="waterfall_item_"]`（搜索列表）、`[class*="video_"]`（详情播放器）、video 直链 `__vid`（单列大视频流）
  - 匹配规律 = **aweme_id 作为 DOM 属性值**，不依赖页面混淆 class
- **下载链路**：隔离世界发 `download_request` → 页面世界 `fetch(url, { credentials: "omit" })` → blob → `<a download>`
  - 关键：抖音 CDN 返回 `Access-Control-Allow-Origin: *`，与 `credentials: "include"` 不兼容会 CORS 拦截，**必须 omit**
- 清晰度过滤：跳过 `adapt_lowest_4_1` / `pay_bvc1_hdr_*` 等自适应/付费/HDR 特殊流，只保留标准清晰度
